Cyanuro es un proyecto que apunta a ser un cliente ligero para Cornet, una plataforma libre de videos y también un file-hoster.

Actualmente ofrecemos 3 versiones para Cyanuro

Cyanuro Web: La versión original de Cyanuro, ideal para la mayoría de dispositivos.
Solo accede a https://www.cyanuro.lovable.app y empieza a mirar.

Cyanuro Mobile: La versión movil de Cyanuro para Android, lo mismo pero para la pantalla pequeña.

Cyanuro para Android TV: La versión para la pantalla grande de Cyanuro, ideal para consumir de forma sencilla.
